# Mirror testing

This directory describes how Mirror proves correctness.

Mirror uses multiple layers of test coverage:

1. install smoke tests
2. import smoke tests
3. discovery smoke tests
4. contract smoke tests
5. end-to-end lab tests
6. offline kernel tests
7. compatibility matrix tests
8. online reference-site tests
9. benchmark tests

The goal is not only to see whether the code runs.
The goal is to see whether the kernel, the packages, and the documentation all agree.
