# Contributor guide

Before you change code, read these in order:

1. `docs/ARCHITECTURE.md`
2. `docs/ALPHA_CONTRACT.md`
3. `docs/SIGNAL_CONTRACT.md`
4. `docs/MIDDLEWARE_CONTRACT.md`
5. `docs/reference/capabilities.md`
6. `docs/reference/mirror_core.md`
7. `docs/tutorials/capability_quickstart.md`

The architecture document is the source of truth. If code and docs disagree,
the code must change or the feature must be marked experimental.
