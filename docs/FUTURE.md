# Future Work

This file collects ideas that are intentionally out of scope for the frozen alpha.

## Deferred to beta

- distributed workers
- dashboard and Django integration
- REST and GraphQL interfaces
- scheduling service
- SaaS multi-tenancy
- billing
- Kubernetes orchestration
- cluster scheduling

## Possible later additions

- browser automation providers
- search and indexing capabilities
- monitoring and diff capabilities
- remote worker backends
- provider-specific dashboards
- hosted control planes

These ideas do not change the alpha contract unless an ADR says otherwise.
